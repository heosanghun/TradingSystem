# 공동 작업 규약 (CC · AG · CX)

이 폴더는 세 에이전트가 같은 저장소에서 충돌 없이 일하기 위한 유일한 소통 창구입니다.

- **CC** = Claude Code, **AG** = Antigravity, **CX** = Codex
- 목표: 2026-12-01 2차 심사 전까지 개정본의 빈칸 27칸과 제VI장 전체를 실측값으로 채운다. 수치 동결은 11-25.
- 배경 문서: `구현계획_261111.md`, 검증 결과는 `collab/handoffs/CC_검증_261112.md`

## 매번 작업을 시작할 때

1. `git pull --rebase`
2. `collab/BOARD.md`에서 자기 작업의 상태를 확인한다.
3. `collab/inbox/<자기 이름>.md`의 지시를 위에서부터 수행한다.
4. `collab/DECISIONS.md`에서 사용자 결정이 새로 났는지 확인한다.

## 자율 진행 (사용자가 매번 지시하지 않아도 계속하는 방법)

사용자는 처음 한 번만 각 에이전트를 깨웁니다. 그 뒤에는 아래를 반복합니다.

1. inbox의 작업 하나를 끝내면 인계 기록을 쓰고 `BOARD.md`를 갱신해 커밋·push한다.
2. 멈추지 말고 `git pull --rebase` 후 `BOARD.md`, 자기 inbox(특히 맨 아래 "요청" 절), `DECISIONS.md`를 다시 읽는다.
3. 선행 조건이 충족된 다음 작업을 바로 시작한다.
4. 사용자 결정이 필요하면 `DECISIONS.md`에 질문을 추가하고, "결정 전 기본 동작"으로 계속하거나 다른 작업으로 넘어간다. 결정을 기다리며 멈추지 않는다.
5. 할 수 있는 작업이 하나도 없을 때만 멈춘다. 멈출 때는 `BOARD.md` 변경 기록에 "무엇을 기다리는지"를 한 줄 적는다.
6. 다시 깨어나면(사용자 입력, 예약 실행, 다른 에이전트의 요청) 2번부터 이어 간다.

각 앱에 반복 실행·예약 기능이 있으면 30~60분 간격으로 "collab 보드를 확인하고 이어서 진행"을 걸어 둡니다. 없으면 사용자가 "계속"이라고만 입력하면 됩니다.

## 규칙

1. **파일 소유권.** `ROLES.md`의 소유 경로만 수정한다. 남의 경로를 고쳐야 하면 그 에이전트의 inbox 맨 아래 "요청" 절에 한 줄로 적고, 직접 고치지 않는다.
2. **작업 선점.** 시작 전에 `BOARD.md`의 해당 행을 `진행`으로 바꾸고 그 변경부터 커밋한다. `진행` 상태인 남의 작업은 건드리지 않는다.
3. **커밋.** 자기 경로만 `git add <경로>`로 올린다. `git add -A`, `git add .`는 쓰지 않는다. 메시지는 `[AG] T-101 차트 메모리 축소` 형식. push 전에 `git pull --rebase`. 강제 push 금지.
4. **완료 기준.** 각 작업의 "완료 조건"을 실제 실행으로 확인하고, `pytest -q` 전체 통과 후 `handoffs/`에 인계 기록을 남긴 다음 `BOARD.md`를 `검토 요청`으로 바꾼다. `완료`로 바꾸는 것은 CC만 한다.
5. **수치 무결성.**
   - 사후 보정(스케일, 반전, 혼합, 상한) 코드를 넣지 않는다.
   - 스모크 실행(`--quick-verify`, 모의 LLM, 해시 임베딩, 축소 에폭)의 결과를 `ledger/numbers.csv`에 쓰지 않는다.
   - 논문에 들어갈 수치는 CC가 대장과 로그를 대조해 승인한 것만 쓴다.
   - 결과가 기대와 달라도 그대로 보고한다. 수치를 맞추려고 설정을 바꾸지 않는다.
6. **본 실행은 한 번에 하나.** GPU와 RAM이 한 대뿐이다(RTX 5090 24GB, RAM 31GB). 1시간 넘는 실행은 `BOARD.md`의 "장시간 실행" 표에 시작·예상 종료 시각을 적고, 다른 실행이 있으면 기다린다.
7. **논문 서술과 구현이 다를 때.** 임의로 정하지 않는다. `DECISIONS.md`에 선택지와 권장안을 적고, 결정 전에는 구현을 논문 쪽에 맞춰 둔다.
8. **모르는 것은 추측하지 않는다.** 확인하지 못한 것은 인계 기록에 "미확인"으로 적는다.

## 인계 기록 형식

`collab/handoffs/<에이전트>_<작업ID>_<YYMMDD>.md`

```
# <작업ID> <제목>
- 상태: 검토 요청 | 막힘
- 커밋: <해시>
## 바꾼 것
## 확인한 방법 (실행 명령과 출력 요약)
## 확인하지 못한 것
## 다음 사람이 알아야 할 것
```

## 폴더 구성

| 경로 | 용도 | 쓰는 사람 |
|---|---|---|
| `README.md` | 이 규약 | CC |
| `ROLES.md` | 역할과 파일 소유권 | CC |
| `BOARD.md` | 작업 보드, 장시간 실행 표 | 전원(자기 행만) |
| `inbox/CC.md` `inbox/AG.md` `inbox/CX.md` | 에이전트별 지시문 | CC가 작성, 각자 "요청" 절만 추가 |
| `handoffs/` | 인계·검토 기록 | 전원 |
| `RELEASE.md` | 공개 저장소 정리 기준 | CC |
| `kickoff/` | 각 에이전트를 처음 깨울 때 붙여 넣는 글 | CC |
| `DECISIONS.md` | 사용자 결정 대기·완료 목록 | 전원이 질문 추가, 답은 사용자 |
