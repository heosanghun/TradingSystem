# T-201 시간봉 입력 정합성과 실제 자료 확보
- 상태: 막힘 (입력 검증 코드는 작성; 실제 거시 시간봉 수신 미완)
## 바꾼 것
- src/ts/data/macro_fetcher.py: 일봉→시간봉 대체 제거. 실제 시간봉 로컬 아카이브 메타데이터/시간 간격/양수 가격 검사. 봉 시작 표시는 종가 가용 시각으로 1시간 이동.
- 이전 관측값만 시간 격자에 유지, 시작 관측가 부재·지나치게 오래된 끝 자료 제외. 각 제외 종목/사유를 last_universe_report와 연구2 metrics.universe에 기록.
- 명시적으로 prefer_hourly=False를 요청한 미국 ETF 일봉 비교만 별도 허용하고 뉴욕 16시(DST 반영)로 가용 시각 표시.
- src/ts/data/binance_fetcher.py: HTTP 실패·응답 오류 로그 후 대체 엔드포인트 시도. 조용한 실패 제거.
- data/DATA_SOURCES.md: 60개 요청 종목별 후보 공급자와 실제 확보 여부, 실제 BTC 캐시 행 수/해시, 입력 계약과 한계.
- data/collect_inputs.py: 기존 Binance 수집기의 CLI와 시간봉 아카이브 검사 도구.
- src/ts/data/__init__.py, src/ts/study2/__init__.py: 지연 import로 WP0가 연구2 전체를 불러오지 않도록 분리.
## 검증
- 관측시각 08:30/09:30/10:30을 정각 격자에 맞추는 테스트: 미래 종가를 앞당겨 쓰지 않음, 새 관측 없는 구간 수익률 0.
- 일봉/누락 종목 제외 이유 기록, 시간봉 통계의 SPY 자동 일봉 대체 거절, 미국 DST 전후 UTC 가용시각 21시/20시 검증.
## 미완
- 실제 거시 시간봉 0개 수신. DNS 제한 및 공급자 키/권한이 없어 종목별 공급 범위·결측률을 검증하지 못함.
- 장외 휴장과 공급자 중간 누락을 자동 분리하지 못함. 거래소 캘린더 검증 필요.
- 공식 후보: Alpaca historical stock bars(계정·키 필요; IEX/SIP 차이 기록). FX·지수는 공급자 아카이브 필요. 지수/금리를 ETF로 임의 치환하지 않음.
## 인계
- 네트워크 가능한 CC에게 실제 거시 시간봉 수신을 요청함. source 메타데이터를 포함한 parquet를 cache에 두면 검증 경로를 사용할 수 있음.
- data/ 아래 문서/수집 소스는 gitignore 대상: data/DATA_SOURCES.md, data/collect_inputs.py 두 파일만 명시해 -f로 커밋. 원본 데이터는 커밋하지 않음.
