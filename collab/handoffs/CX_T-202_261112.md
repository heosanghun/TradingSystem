# T-202 실뉴스 확보와 전처리
- 상태: 막힘
## 바꾼 것
- data/collect_inputs.py prepare-news: 입력의 출처/이용 조건 기록, 명시 시간대 필수, 요청 기간 필터, 뉴스 스토어를 통한 중복 제거, 출처별/월별 건수 보고. 빈 달이 있으면 완료 parquet를 내보내지 않음.
- scripts/run_study2.py: 빈 뉴스 파일 거절, 본 실행에서 평가 기간의 월별 빈 달 거절. 테스트 진단은 별도 모드.
- data/DATA_SOURCES.md에 실제 뉴스 미확보와 라이선스 미확정 상태 기록.
## 검증
- 출처가 표시된 테스트 픽스처로 중복 제거·빈 달 보고·모호한 무시간대 발행일 거절 확인. 테스트 자료를 실뉴스로 사용하지 않음.
## 미완
- Hugging Face 공개 데이터셋 검색 API 요청은 DNS 실패. 실제 원문 수신 0건.
- 이 도구는 확보한 권한 있는 아카이브의 전처리기이며 수집기나 출처 진위 검증기를 완성한 것이 아님.
- Bloomberg/Reuters/CoinDesk 245,000건 수신·기간·이용 조건 미확인.
## 인계
- 네트워크 가능한 CC에게 이용 조건이 확인되는 실제 뉴스 출처 수신을 요청함. 수신 뒤 전체 기간 빈 달과 출처를 이 도구로 검사해야 함.
