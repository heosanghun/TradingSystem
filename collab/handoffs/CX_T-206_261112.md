- 기준 커밋: 0ce0f57
## 공식 자료 확인
- https://docs.tardis.dev/historical-data-details/binance
- https://docs.tardis.dev/downloadable-csv-files/api
- https://docs.tardis.dev/downloadable-csv-files/data-types
- 매월 1일 표본은 API 키 없이 다운로드 가능. Binance Spot BTCUSDT의 book_snapshot_25가 안내됨.
- 스냅샷은 25단계 호가 변화마다 생성되며 고정 100ms 간격이라고 가정할 수 없음.
- book_snapshot_25에는 체결량·매수/매도 체결 방향이 없으므로 trades도 별도 수집 후 시점 정렬해야 40특징 전체를 검증할 수 있음. 누락 체결값을 임의로 0으로 채워 실측이라고 하지 않음.
## 실제 시도
- https://datasets.tardis.dev/v1/binance/book_snapshot_25/2022/05/01/BTCUSDT.csv.gz
- https://api.tardis.dev/v1/exchanges/binance
- 두 요청 모두 실행 환경 DNS 실패(NameResolutionError). 데이터 다운로드 0건.
## 확인하지 못한 것
- 하루 파일 크기, 실제 틱 간격, 윈도우 생성, 전 기간 용량, 요금 미확인. 무료 표본 존재가 전체 기간 무료 이용·재배포 허용을 뜻하지 않음.
