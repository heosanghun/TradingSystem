# T-208 자기 경로 공개 정리
- 상태: 막힘 (교차 소유 테스트/실행기의 모의 경로 분리 대기; 나머지 로컬 보완 검토 가능)
## 바꾼 것
- src/ts/study2/causality.py: 시차 요약 3차원 KDE·정규화 하한·다중비교 미보정 한계를 명시, full TE 추정량의 일치성 주장 제거.
- src/ts/baselines/models.py: 기존 MAMLMetaPPOBaseline이 Reptile식 파라미터 보간임을 명시. 클래스명은 호환용으로 유지, D-11 질문 추가. 알고리즘과 결과는 바꾸지 않음.
- src/ts/data/lob_processor.py: 대용 특징은 L2 복원이 아니며 표본 시간·추정 채널·초기 반복 패딩이 다름을 명시.
- src/ts/study2/debate.py, citation_verifier.py, hypergraph.py와 두 실행 스크립트: 근거 없는 Exact 문구 정리. 프롬프트의 exact schema 지시는 출력 계약이므로 유지.
- src/ts/data/binance_fetcher.py, macro_fetcher.py: 실패 로그와 명시적 제외 기록. 대상 data/study2/baselines에 except Exception pass/continue 잔존 없음.
- data/DATA_SOURCES.md, data/collect_inputs.py: 실제 자료/후보 구분, UTC 가용 시각·출처·이용 조건·월별 분포 점검과 재현 절차.
- tests/test_study2_pipeline.py: EconometricTestClient를 테스트 전용으로 준비.
## 아직 끝내지 못한 것
- production LLMClient의 deterministic_econometric 경로와 뉴스의 offline_hash_mode 생성기는 아직 제거 전. AG 소유 tests/test_full_fig1_flow.py와 scripts/run_full_pipeline.py/연구1 감성 테스트 호출이 의존해 AG에게 교체 요청함. 소유권 규약상 직접 바꾸지 않음.
- 실제 다운로드 경로의 완전 재현은 네트워크 가능한 환경과 데이터 권한 확인이 필요. T-201/T-202 인계 참조.
- README의 논문과 차이, 모델 명칭/평가표 변경은 AG·CC가 담당. D-11 결정 전 MAML로 성과 확정하지 않음.
